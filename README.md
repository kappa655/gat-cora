# GAT on Cora

A Graph Attention Network (GAT) for node classification on the Cora citation network dataset, implemented with PyTorch Geometric.

## Features

- Multi-head Graph Attention Network
- Node classification on the Cora dataset
- Accuracy, Precision, Recall and Macro-F1 evaluation
- Confusion matrix and per-class F1 scores
- Attention visualization
- t-SNE visualization of node embeddings
- Interactive Streamlit dashboard

## Technologies

- Python
- PyTorch
- PyTorch Geometric
- Scikit-learn
- Streamlit
